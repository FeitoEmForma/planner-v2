PRIMEIRA CONFIGURAÇÃO

Seu Planner online está quase pronto.

1. Crie um projeto no Supabase ↗.

2. Execute BANCO-DE-DADOS.sql e ATIVAR-MODULOS-STUDIO.sql no SQL Editor.

3. Preencha a URL e a chave publicável no arquivo config.js e publique no GitHub Pages.

Veja o guia COMO-ATIVAR.md no pacote ZIP. Nunca publique a senha do banco nem a service_role key.
